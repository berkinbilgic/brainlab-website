# BRAIN Lab website

Source of the website of the BRAIN Lab (Bilgic Reconstruction Acquisition for Imaging Neuroscience) at the Martinos Center for Biomedical Imaging, Massachusetts General Hospital / Harvard Medical School.

**Live site:** https://www.martinos.org/~berkin/

| Page | Contents |
|---|---|
| `index.html` | About, research interests, biography, contact, news, funding |
| `team.html` | Faculty, research fellows, students and alumni |
| `publications.html` | Invited and proffered talks, journal papers, conference papers and abstracts, theses, patents |
| `software.html` | Open-source code, data and pulse sequences, most of them in the [berkinbilgic](https://github.com/berkinbilgic) repositories |
| `images/` | Photos shown on the home and team pages |

## Notes

- **No build step:** plain static HTML, with the CSS inside each page. Fonts are DM Sans and DM Mono, from Google Fonts.
- **Design:** dark theme by default. The layout is inspired by the [PRIME Lab](https://primelab.korea.ac.kr/) website.
- **Journal list:** the Journal Publications list on `publications.html` is refreshed from PubMed every week.
- **Linked files are not here:** papers, slides, the CV and toolbox archives are hosted on the live site. Links to them only work at martinos.org.
